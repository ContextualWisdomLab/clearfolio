🛡️ Sentinel: [CRITICAL] Fix weak default fallbacks for secrets

🚨 Severity: CRITICAL
💡 Vulnerability: Spring Boot `@Value` annotations used default empty string fallbacks (`@Value("${secret:}")`) for security-critical secrets like HMAC keys.
🎯 Impact: If a secret is omitted from the production environment config, the app boots silently using an empty string as the key, compromising all cryptographic operations.
🔧 Fix: Removed default fallbacks from `@Value` for security-critical properties, forcing a hard context initialization failure on missing config.
✅ Verification: Tested locally via `mvn verify` ensuring `IllegalArgumentException` is raised when required secrets are omitted.
