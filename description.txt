💡 What: `String.split(",")`과 Java Stream을 사용하던 문자열 파싱을 수동 루프와 `indexOf()`, `substring()`을 사용하도록 최적화했습니다.
🎯 Why: 간단한 구분 기호 토큰을 파싱할 때 `String.split()`과 Stream을 사용하는 것은 불필요한 배열 할당과 함수형 오버헤드를 발생시켜 가비지 컬렉션(GC) 압박을 줍니다. 수동 루프로 전환하여 이러한 오버헤드를 제거했습니다.
📊 Impact: 문자열 파싱 시 불필요한 객체 할당을 방지하여 메모리 사용량을 줄이고 성능을 향상시킵니다.
🔬 Measurement: `mvn -B --no-transfer-progress verify` 명령어를 통해 전체 테스트가 성공적으로 통과하고 100% 코드 커버리지가 유지되는지 확인할 수 있습니다.
